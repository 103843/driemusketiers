# Team Charter: [Drie musketiers] 
 
## 1. Onze Ambitie 
* [Wat willen jullie als team bereiken qua cijfer en leermomenten?] 
Als team willen wij werken aan het verbeteren van onze codeer vaardigheden. Tijdens dit project willen wij gaan focussen op dat er geen miscommunicatie ontstaat, om problemen te voorkomen. Als team werken we ook aan een sterke samenwerking tussen de verschillende rollen in ons team. Uiteindelijk streven wij naar een hoog cijfer.

## 3. GitHub & Code Afspraken 
* **Branching:** Niemand commit rechtstreeks naar `main`. We werken via
branches. 
* **Pull Requests (PR):** Een PR mag pas worden gemerged als minimaal 1
ander teamlid een "Approve" (Code Review) heeft gegeven. 
 
## 4. De Pre-Mortem (Risico Analyse) 
*Fast-forward naar week 7: het project is genadeloos gefaald. Wat ging er
mis en hoe voorkomen we dit nu al?* 
* **Risico 1:** 
- we liepen vast op technische obstakels

  * *Oplossing vooraf:* 
- docent op tijd om hulp vragen, niet last minute.

* **Risico 2:** 
- slechte communicatie van teamleden buiten de les
 
  * *Oplossing vooraf:* 
- via teams communiceren buiten school

* **Risico 3:** 
- onduidelijke taakverdeling

  * *Oplossing vooraf:* 
- vooraf voor dat we aan het werk gaan samen duidelijk overleggen wie wat gaat doen.

 
## 5. Consequenties

- 2e keer = waarschuwing
- 3e keer = docent inlichten
