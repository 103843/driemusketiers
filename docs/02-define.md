# Fase 2: Define (Kaders & Probleemstelling)
 
## 1. De Probleemstelling (Point of View)
*Gen z heeft een manier nodig om goedkope, snelle maaltijden te plannen omdat ze geïnspireerd moeten worden om zelf te gaan koken. *

 
## 2. Programma van Eisen (MoSCoW)
**Must Haves:**
- de app moet responsive zijn.
- navigatie bar
- Gebruikers kunnen zelf recepten aanmaken, aanpassen en verwijderen, en recepten van andere gebruikers bekijken. 
- user interface moet gericht zijn op het aanspreken van gen Z
 
**Should Haves:**
- dark mode
- social media integraties


**Could haves:**
- gamingfication/streaks
- AI-kookassistent
- spotify kook afspeellijsten


**Won't Haves (Buiten scope):**
- Integratie met echte supermarkt API's
- betaalde aboonnement
- lange blogartikelen
